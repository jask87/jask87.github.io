Young Men Invitations

Each young man picks one invitation. Tap a choice to save it; tap it again to clear it.

Add the names

Paste or type one name per line. A line like Deacons or Teachers: starts a group. You can paste the name column straight from the spreadsheet; “Last, First” is turned into “First Last”.

Names are saved only on this device.

Restore from backup

Paste a summary you copied earlier with “Copy summary”. This replaces the names and choices on this device.

Summary

Select all of this text and copy it into Notes or a message.

Everything is stored only in this browser on this device. Nothing is sent anywhere. Tip: use “Copy summary” now and then and keep it in Notes as a backup.
